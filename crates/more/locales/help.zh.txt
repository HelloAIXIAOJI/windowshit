一次显示一屏输出。

MORE [/E [/C] [/P] [/S] [/Tn] [+n]] < [drive:][path]filename
command-name | MORE [/E [/C] [/P] [/S] [/Tn] [+n]]
MORE /E [/C] [/P] [/S] [/Tn] [+n] [files]

    [drive:][path]filename  指定要一次显示一屏的文件。

    command-name            指定要显示其输出的命令。

    /E      启用扩展功能
    /C      显示页面前清除屏幕
    /P      展开换页符
    /S      将多个空白行压缩为单个行
    /Tn     将制表符展开为 n 个空格（默认 8）

            开关可以出现在 MORE 环境变量中。

    +n      从第 n 行开始显示第一个文件

    files   要显示的文件列表。列表中的文件用空格分隔。

    如果启用了扩展功能，则在 -- More -- 提示符下接受以下命令：

    P n     显示以下 n 行
    S n     跳过以下 n 行
    F       显示下一个文件
    Q       退出
    =       显示行号
    ?       显示帮助行
    <空格>  显示下一页
    <回车>  显示下一行
